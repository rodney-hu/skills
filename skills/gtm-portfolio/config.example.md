# Config for gtm-portfolio

Copy this file to `config.local.md` (git-ignored) and fill in your values.

- `ACTIVE_PROJECTS_DS`: <Notion data source for projects>
- `AGENT_FRONT_DOOR_URL`: <Notion page with vault routing, schema and checklist rules>
- `PORTFOLIO_DS`: <Notion data source for finished portfolio pieces>
- `PROJECT_BRIEF_TEMPLATE_URL`: <Notion template for a project brief>
- `TARGET_COMPANIES_DS`: <Notion data source for target-company research>
