# Hypnotic Copy Skill

You are writing influence-engineered copy. Every word is structural. Every sentence either paces, leads, presupposes, or embeds. Nothing is filler.

---

## Step 1: Intake — Identify the Deployment Environment

Before writing a single word, classify the asset:

| Format | Primary Mechanism | Length Target |
|---|---|---|
| **Social Post** | Open Loop + Presupposition + Pattern Interrupt | 150–300 words |
| **Email (EEC / Broadcast)** | Pacing → Leading + Embedded Commands + Future-Pace | 250–500 words |
| **Sales Page / VSL Script** | Full 13-component hypnotic letter structure | 800–2000+ words |
| **Opt-In / Landing Page** | Presupposition headline + Yes Set + Single CTA | 200–500 words |
| **Cold Outreach** | Pacing truism + Piggyback Principle + Soft CTA | 100–200 words |
| **Hypnosis Script** | Full 5-phase induction architecture | 500–1500 words |
| **Social DM / Nurture** | Agreement momentum + Conversational postulate | 50–150 words |

Then collect:
- **Subject/Topic** — What is the copy about?
- **Target Reader** — Who is this written for? What state are they in right now?
- **Desired Outcome** — What belief, feeling, or action should they have after reading?
- **Mechanism / Offer** — What is being presented or sold?
- **Tone** — Clinical authority? Intimate mentor? Pattern-interrupt challenger?

## Step 2: Apply the Right Architecture

### FOR SOCIAL POSTS

Use this sequence:
1. **Pattern Interrupt Headline** — Violate an expectation. Create cognitive dissonance.
2. **Pacing Truism** — 1–2 sentences they'd nod yes to immediately.
3. **Open Loop** — Begin a story or idea, do NOT complete it yet.
4. **Presupposition Stack** — 3–5 embedded presuppositions (see taxonomy below).
5. **Embedded Command Cluster** — 2–3 covert directives inside natural sentences.
6. **Loop Close + CTA** — Resolve the open loop. Direct to next action.

### FOR EMAILS

Use this sequence:
1. **Subject Line** — Curiosity gap + presupposition (e.g., "The belief that's keeping you stuck")
2. **Opening Pacing Block** — Mirror their current reality. 2–3 sensory truisms.
3. **Bridge via Piggyback Principle** — Attach the leading suggestion to the agreed-upon truth.
4. **Never-Ending Sentence Transition** — Link truisms → lead using *and, as, while*.
5. **Story / Case Study** — Open loop narrative. Insert embedded commands inside the story.
6. **Presupposition Payload** — Temporal connectives, awareness predicates, ordinal numerals.
7. **Future-Pace** — Paint the post-compliance identity. Revivification.
8. **CTA as Conversational Postulate** — "Can you imagine what's possible once you...?"

### FOR SALES PAGES / VSL SCRIPTS

Follow the **13-component hypnotic letter structure**:
1. Headline (benefit-forward, presupposes outcome)
2. Headline Design (readable, no gimmicks)
3. Promise + Curiosity hook
4. Letterhead/Authority signal
5. Opening Paragraph (question, metaphor, or story)
6. Offer (stated clearly and early)
7. Advantages (physical, emotional, logical stacked)
8. Positive Language only (what TO do, never NOT to do)
9. Emphasis via typographical marking (see below)
10. Egometer — "you" appears 3–5x more than "I/we"
11. Short sentences for readability (<20 words preferred)
12. Structure for skimmers AND readers (sub-heads every 150–200 words)
13. Personal, intimate, one-person tone throughout

### FOR HYPNOSIS SCRIPTS

Follow the **5-phase architecture**:
1. **Pre-Talk** — Demystify. Remove fear. Establish safety. Plant implicit learning frame.
2. **Induction** — Progressive relaxation (Jacobson method) OR pattern interrupt shock induction.
3. **Deepening** — Countdowns, spatial metaphors, somatic gerund compounding ("melting into the chair...").
4. **Suggestion Engine** — Open loops + storytelling + metaphor to install the target belief/behavior.
5. **Awakening** — Ascending count + grounding + amnesia suggestion to protect the install.

Post-hypnotic suggestions must include: (1) predictable trigger, (2) simple action, (3) present/continuous tense, (4) positive framing, (5) single behavior only.

## Step 3: Presupposition Toolkit — Embed These into Every Asset

### Core Taxonomy

| Type | Trigger Words | Example |
|---|---|---|
| **Temporal** | before, after, when, as soon as, during, still, soon | "When you finish reading this, deciding feels natural." |
| **Ordinal** | first, second, next, then | "First, something shifts. Then everything follows." |
| **Awareness Predicate** | realize, notice, discover, recognize, be aware | "Notice how this is already starting to make sense." |
| **Either/Or (False Dichotomy)** | or, whether...or | "Whether you take action now or later today, you already know." |
| **Adverbial Quality** | easily, naturally, comfortably, quickly | "The right decision comes naturally when you trust your clarity." |
| **Change of State** | begin, start, stop, continue, proceed | "As you continue absorbing this..." |
| **Commentary** | fortunately, fascinatingly, surprisingly | "Fascinatingly, your subconscious has already decided." |
| **Existence** | Definite noun phrases | "The certainty within you is ready to expand." |

**Stack rule:** Use minimum 3 presupposition types per major copy block. Never cluster more than 2 of the same type consecutively.

## Step 4: Embedded Command Placement

Embedded commands are **direct instructions hidden inside longer sentences**. The conscious mind reads the sentence; the subconscious receives the command.

**Formula:**
> [Soft weasel opener] + [natural sentence context] + **[COMMAND]** + [continuation]

**Weasel openers:** *"I don't know if you've noticed...", "Some people find that...", "It's interesting how...", "As one begins to...", "I wonder if you can..."*

**Typographical marking for written copy:**
- Use **bold**, *italics*, or a natural pause (em-dash or ellipsis) to mark the command
- Example: *"I don't know exactly when you'll **decide to move forward**, but something tells me it's already closer than you think."*

**Negation hack:** "Don't think about how good it'll feel to finally have this solved." → Forces visualization of the desired state.

## Step 5: Pacing → Leading Sequence

**Never lead without pacing first.** The ratio is: 3 truisms : 1 lead.

**Never-Ending Sentence template:**
> "As you [sensory truism 1], and [sensory truism 2], while [sensory truism 3], [LEADING SUGGESTION]."

**Example:**
> "As you read these words, and feel the weight of everything you've been carrying, while part of you already knows the answer — the path forward is simpler than it's seemed."

**Piggyback Principle:** Validate something they've already done → immediately bridge to the next desired action.
> "The fact that you've already [past success] proves that you have what it takes to [target action]."

---

## Step 6: Open Loop Architecture

Every asset longer than 300 words should have at least **one open loop**.

**How to open a loop:**
- Begin a story, metaphor, or case study
- Interrupt it before the resolution
- Insert your core copy, offer, or CTA section
- Return to close the story in the final paragraph

**Purpose:** Keeps conscious mind engaged, prevents dropout, drives to CTA.

## Step 7: Quality Check Before Delivering

Run each asset through this checklist:

- [ ] **Yes Set established** in opening paragraph (3+ truisms the reader agrees with)
- [ ] **Minimum 3 presupposition types** embedded across the body
- [ ] **At least 2 embedded commands** with analogical marking
- [ ] **Pacing → Leading** transition is present and structurally sound
- [ ] **"You" language dominates** (egometer check: 3:1 "you" to "I/we")
- [ ] **No negative framing** — all commands state what TO feel/do
- [ ] **Open loop** present in assets > 300 words
- [ ] **Future-pace** present (paint the identity post-compliance)
- [ ] **CTA is a conversational postulate**, not a hard command
- [ ] **Typographical marking** used for at least one embedded command

## Formatting Conventions

**Typographical marking in written copy:**

| Vocal Cue | Written Equivalent | Function |
|---|---|---|
| Pitch drop | *Italics* | Mark embedded command |
| Emphasis | **Bold** | Mark key presupposition or command |
| Micro-pause | ... or — | Break reading cadence, insert processing space |
| Source scramble | "Someone once told me..." | Nested quote for covert delivery |

**Sentence length rule:** Alternate short (< 8 words) and long sentences to control reading rhythm and prevent conscious parsing.

## Failure Modes to Avoid

- **Hard selling without pacing** → resistance spikes, copy dies
- **Stacking too many commands explicitly** → reads like manipulation, breaks rapport
- **Leading before truisms are established** → no agreement momentum
- **Negative framing in commands** → subconscious ignores the "not"
- **Closing the loop too early** → reader has no reason to keep reading
- **"I/we" dominant copy** → ego belongs to the reader, not the writer
