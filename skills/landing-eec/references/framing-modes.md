# Framing Modes

The landing page structure and conversion architecture are identical across all modes. Only the vocabulary changes — the words that describe the experience to the visitor. This file defines the full copy vocabulary for each supported framing.

---

## Supported Modes

| Mode | Feel | Best for |
|---|---|---|
| `challenge` | Commitment, participation, experience | Transformation, habit-building, audience activation |
| `course` | Education, structured learning, expertise | Knowledge-heavy offers, professional upskilling, B2B |
| `sprint` | Speed, momentum, time-boxed execution | Operators, builders, people who want fast results |
| `bootcamp` | Intensity, immersion, no-nonsense | High-stakes transformation, serious audiences |
| `workshop` | Guided, hands-on, collaborative | Creative work, practitioner skills, done-with-you feel |

---

## Framing Detection Rules

**If the user or brand context specifies a framing explicitly** → use it.

**If not specified**, infer from brand signals:

| Brand Signal | Inferred Mode |
|---|---|
| Transformation language, habit-based content, community-driven | `challenge` |
| Curriculum, modules, expertise-first content, credentials | `course` |
| Operator/builder audience, speed language, quick wins | `sprint` |
| High-ticket, intensive, "no excuses" brand voice | `bootcamp` |
| Done-with-you, creative, skills-based, practitioner | `workshop` |

**Default if unclear:** `challenge` — it's the highest-commitment framing and works across most audiences.

## Day Label Variants

All modes use `"Day 1"` through `"Day 5"` as the day number label — this is consistent and doesn't change with framing. The noun in the section label and day titles adapts instead.

| Mode | Day action noun (used in day titles) |
|---|---|
| `challenge` | Move, challenge, fix |
| `course` | Lesson, concept, module |
| `sprint` | Task, build, ship |
| `bootcamp` | Drill, rep, exercise |
| `workshop` | Exercise, session, build |

---

## Framing + Brand Voice Compatibility

Some modes conflict with certain brand voices. Respect these guardrails:

| Brand Voice | Avoid | Use Instead |
|---|---|---|
| Formal / enterprise | `bootcamp`, `sprint` slang ("Drop out anytime") | `course` or `workshop` with formal trust signals |
| Casual / creator-led | Stiff `course` language ("enrolled", "curriculum") | `challenge` or `sprint` |
| High-touch / coaching | Impersonal `sprint` or `bootcamp` | `workshop` or `challenge` |
| Technical / operator | Fluffy `workshop` language | `sprint` or `challenge` |
