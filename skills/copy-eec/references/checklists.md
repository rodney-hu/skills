# Quality Control Checklists

## Offer Checklist

### Required Elements
- [ ] Specific audience (not "people")
- [ ] Exactly 5 mistakes listed
- [ ] Exactly 3 outcomes in subtitle
- [ ] Golden word in name (Roadmap, Blueprint, System, etc.)
- [ ] Main whisper: "(And How To Solve Them)"

### Tangibility Check
- [ ] At least 2/3 outcomes have numbers (time, money, quantity)
- [ ] Outcomes use concrete imagery (specific scenarios)
- [ ] No vague words (struggle, difficult, frustrated)

### Polish
- [ ] No duplicate words between name and subtitle
- [ ] Outcomes feel painful and immediate
- [ ] Passes "soul-stare test" (would target audience opt in immediately?)

## Outline Checklist

### Structure
- [ ] Has Day 0 (welcome email)
- [ ] Has 5 content days (Days 1-5)
- [ ] Each day covers one mistake
- [ ] Mistakes don't overlap significantly

### Flow
- [ ] Logical progression (beginner → advanced OR most common → least common)
- [ ] Each mistake is distinct
- [ ] Fix for Mistake 1 doesn't solve Mistake 2

### Preview
- [ ] Day 0 previews all 5 mistakes
- [ ] Each day (1-4) previews next day
- [ ] Day 5 wraps up without preview

## Email Copy Checklist

### Structure (Per Email)
- [ ] Has Section 1: The Reminder
- [ ] Has Section 2: The Mistake
- [ ] Has Section 3: The Reason This Happens
- [ ] Has Section 4: How To Fix It
- [ ] Has Section 5: Check Your Inbox Tomorrow (or final wrap)

### 1/3/1 Rhythm
- [ ] Section 2 prose = 1 opener + 3 explanation + 1 conclusion
- [ ] Section 3 prose = 1 opener + 3 explanation + 1 conclusion
- [ ] Section 4 prose = 1 opener + 3 explanation + 1 conclusion

### Bullets
- [ ] Section 2 has 3-5 outcome bullets
- [ ] Section 3 has 3-5 reason bullets
- [ ] Section 4 has 3-5 action bullets
- [ ] Each bullet is 1-3 sentences (not single lines)
- [ ] Bullets include specific examples or details

### Language
- [ ] Uses "you" (second person) throughout
- [ ] No business jargon (leverage, optimize, synergies, utilize, implement)
- [ ] No weak words (might, could, maybe, probably, sort of, kinda)
- [ ] Short sentences (mostly under 20 words)
- [ ] Active voice

### Tangibility
- [ ] Specific numbers where possible
- [ ] Concrete scenarios (not abstractions)
- [ ] Vivid imagery
- [ ] No vague outcomes

### Length & Scannability
- [ ] Under 1000 words total
- [ ] Uses headers for each section
- [ ] Line breaks between paragraphs
- [ ] Bullets properly formatted
- [ ] Easy to scan in 30 seconds

### Subject Line
- [ ] Format: "{Course Name} - Day {X}: Mistake #{X}"
- [ ] Clear and descriptive
- [ ] Consistent across all days

## PS Checklist (If Monetizing)

### Alignment
- [ ] PS relates to email topic
- [ ] PS doesn't disrupt flow
- [ ] Only one PS per email

### Deployment
- [ ] Days 1-2 = soft sell (awareness)
- [ ] Days 3-4 = medium sell (value + proof)
- [ ] Day 5 = strong sell (urgency)

### Content
- [ ] Clear value proposition
- [ ] Specific transformation promised
- [ ] Link or CTA included
- [ ] Feels natural (not forced)

## Deployment Checklist

### Email Sequence
- [ ] All 6 emails written (Day 0 + Days 1-5)
- [ ] Passed all copy checklists above
- [ ] Subject lines consistent
- [ ] Author name consistent

### Technical Setup
- [ ] Emails formatted correctly for platform (ConvertKit, MailChimp, etc.)
- [ ] Links work
- [ ] PS links go to correct landing page
- [ ] Sequence timing set (Day 0 = immediate, others = +1 day each)

### Monetization (If Applicable)
- [ ] Landing page for paid offer ready
- [ ] Payment processing set up
- [ ] All PS links point to same offer
- [ ] Bonuses/guarantees mentioned are real

### Testing
- [ ] Send test emails to yourself
- [ ] Check formatting on mobile
- [ ] Verify all links click through
- [ ] Proofread for typos

### Tracking
- [ ] Analytics/tracking set up
- [ ] Open rate tracking enabled
- [ ] Click tracking enabled
- [ ] Unsubscribe link working

## Success Metrics

After deployment, monitor:

**Engagement:**
- Open rate: Target 40%+ (industry average: 20-25%)
- Click rate: Target 3-5% on PS links
- Completion rate: Target 60%+ finish all 5 days
- Unsubscribe rate: Under 2% per email

**Quality Indicators:**
- People reply with "how did you know?" type messages
- Low unsubscribe rate
- High Day 5 completion
- People share with others

**Conversion (If Monetizing):**
- PS click-through rate
- Landing page conversion rate
- Overall EEC → paid conversion rate

## Red Flags

Stop and revise if you see:

- ❌ Open rates under 30% (subject lines or timing issue)
- ❌ Unsubscribe rate over 5% (content mismatch or tone issue)
- ❌ Most drop off after Day 1 (promise vs delivery mismatch)
- ❌ Zero replies or engagement (not resonating)
- ❌ PS links get clicks but no conversions (offer mismatch)
