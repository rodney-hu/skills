# Config for spec-demo

Copy this file to `config.local.md` (git-ignored) and fill in your values.

- `SPEC_DEMO_OUTPUT_DIR`: <folder where each demo is saved, one subfolder per prospect; ideally a git repo shared by your agents>
- `SPEC_DEMO_KIT_DIR`: <local folder holding the spec-demo kit>
- `SPEC_DEMO_REFERENCE`: <folder name of the finished reference demo inside the kit>
